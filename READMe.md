# Cypress API Test Automation (MoxyMind TT2)

## Description
This project contains API test automation using Cypress.

I implemented tests for:
- GET users endpoint
- POST create user endpoint

The tests include:
- Validation of HTTP status codes
- Verification of response data
- Validation of dynamic fields (id and createdAt)
- Response time validation
- Bonus: validation of data types and response schema

---

## Installation

Clone the repository:

git clone https://github.com/enintilka/cypress-api-automation-MoxyMind-TT2.git

Navigate to the project folder:

cd cypress-api-automation-MoxyMind-TT2

Install dependencies:

npm install

---

## Run Tests

Run tests from command line:

npm run cypress:run

Open Cypress UI:

npm run cypress:open
